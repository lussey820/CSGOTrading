配置步骤教程

1. SteamDT 开放平台 饰品数据

提供饰品价格、K 线、以及全量饰品名称数据，图像识别匹配中文名依赖它。

  1. 打开 open.steamdt.com，注册并登录账号。
  2. 进入「开放平台 / OpenAPI」页面，创建一个应用（Application）。
  3. 在应用详情里复制你的 API Key（一串 32 位十六进制字符），粘贴到上方「SteamDT 开放平台」输入框。
  4. 点击「保存配置」。注意：全量饰品接口每天限调用 1 次，首次成功后会缓存 24 小时。

2. 阿里云百炼 DashScope 图像识别 / 看图分析

用于图像识别（OCR 提取饰品名）和今日建议的截图看图分析（qwen-vl-plus 多模态）。

  1. 打开 阿里云百炼控制台，用阿里云账号登录（未开通需实名认证）。
  2. 首次进入按引导「开通百炼 / 模型服务」；在「模型广场」确认可调用 qwen-vl-plus。
  3. 点击右上角头像 →「API-KEY」，或左侧「API-KEY 管理」→ 创建新的 API Key。
  4. 复制以 sk- 开头的密钥，粘贴到上方「阿里云百炼 DashScope」输入框并保存。

3. DeepSeek AI 决策分析

今日建议与 AI 持仓的金融专家分析使用 DeepSeek 大模型。

  1. 打开 platform.deepseek.com，注册并登录。
  2. 在左侧「API Keys」页面点击「创建 API Key」，复制生成的密钥（以 sk- 开头）。
  3. 确保账户内有余额（充值后 API 才能正常调用）。
  4. 粘贴到上方「DeepSeek」输入框并保存。

小提示：密钥保存在项目根目录的 .env 文件中，请勿把该文件提交到公开仓库。 修改后立即写入运行时环境，图像识别 / 看图 / 决策分析下次调用即可生效。
